# EnfrenDados

EnfrenDados is a turn-based dice game for two players, developed as an academic project using C++.

## About the Game

At the beginning of each turn, a target number is generated by rolling two twelve-sided dice. The player then rolls six six-sided dice and must select a combination whose values add up exactly to the target number.

The game consists of three rounds, with one turn per player in each round. The player with the highest score at the end of the game wins.

There is also an automatic victory condition when a player reaches the target number using all six dice.
